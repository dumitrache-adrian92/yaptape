# yaptape

Someone has to talk about the music man.

Yaptape is a place to make mixtapes that say a little more. Add YouTube tracks, put a note beside each one, and share your tape with a short link.

When someone opens a mixtape, the tape comes to life: the first track starts in the player, its note appears alongside it, and the next track follows when it ends. Listeners can skip forward or go back to a track they want to hear again.
